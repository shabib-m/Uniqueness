# Uniqueness (Ported to Backdrop CMS)

This is an **experimental port** of the Drupal 7 [Uniqueness](https://www.drupal.org/project/uniqueness) module to **Backdrop CMS**, initially converted with the assistance of AI tools.

## What does this module do?
The **Uniqueness** module helps avoid duplicate content on your site. It adds an asynchronous UI widget to the content creation/edit form. As users type a title, it performs searches in the background and informs them about similar or related content already existing on the site before they hit save.

## Current Project Status: Seeking a Maintainer!
* **Port Origin:** Drupal 7 version of `uniqueness`.
* **Current State:** AI-assisted automated port. The basic file structure and hooks have been updated for Backdrop CMS (`backdrop = 1.x`).
